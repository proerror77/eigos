# 原任务恢复与执行预算

补充信息、来源连接过期和执行窗口到限均保留原 taskId。恢复不通过另建任务、清空模型记录或伪造新的用户确认来获得执行空间；已确认的业务信息继续作为有来源的输入。订单、付款和其他业务许可仍由原有独立授权规则控制。

## 有限窗口与累计上限

| 档位 | Agent 单段模型调用 | 累计模型调用 | 单段／累计计划 | 单段／累计读取动作 |
| --- | ---: | ---: | ---: | ---: |
| `standard` | 32 | 128 | 8／32 | 16／64 |
| `extended` | 64 | 256 | 16／64 | 32／128 |

尚未选定 Agent 程序的解释及传统规划，单段模型调用上限分别为12和32。一次本体推理交互仍最多8个模型响应，不因长任务档位无限扩展。

本体读取与最终决策至少需要两轮；剩余一轮时提前暂停，保留未使用额度和原记录。单次推理在有限轮次内未形成决策也进入可续办暂停，不能因此把任务写成不可继续的失败。

提交任务可指定档位，默认 `standard`。原任务等待输入时可通过 `reply_to_task` 或 A2A 的同任务 SendMessage 选择 `executionBudget: "extended"`；档位仅可扩大，已用次数不变。模型不能在内部自行修改任务预算。`delegation.executionBudgetStatus` 暴露实际用量、窗口基线、上下限和暂停原因。

只有已接受的本人输入和经过来源状态／请求版本检查的恢复能开启新窗口；相同请求 ID 的重试返回原收据。原模型记录、计划、动作和尝试不重编号、不删除。普通轮询、Worker 领取与续租、被拒绝的恢复请求均不分配窗口。累计上限仍是硬限制；扩展档位也到限时须明确调整策略，重复“继续”不能绕过。

Agent 的连续执行时间使用当前窗口起点，保留原任务创建时间。等待用户或来源接入不消耗下一段时间；本段超时暂停原任务。用户业务要求中的截止时间保持原有含义，不随恢复延后。

## 已确认信息与来源续期

1. 补充信息追加到原请求中；现有要求及其来源保持，修改后的业务事实仍经过解释、条件和输入校验。
2. 已建立 Agent 范围后，在下一次模型调用前检查来源是否失效。纯来源续期保留已有的有效需求解释与程序输入，建立绑定当前连接版本的新范围；业务事实改变时不使用这个快捷恢复路径。
3. 旧观察和计划归档，已确认的读取回执保留原状态。未完成读取按既有取消规则封存，不直接重放；模型必须读取当前范围，明确选择新的读取及完成依据。
4. 同一会员、同一安装、同一凭据的期限续期保留独立的地址选择上下文。不同 Token 需要新旧读取提供一致的供应商账号标识，并处于同一授权 epoch，才能保留选择。每个来源读取仍绑定新的完整 grant revision，旧观察不能充当新连接下的查询结果。
5. 数字选择绑定用户回复前实际展示的列表，并区分寄件／收件方向。再次读取时以地址 ID 和完整内容核对所选项。仅重排或无关地址变更不要求重复选择；所选地址变化才要求新输入。

不同 Token 的上传仍先建立独立选择上下文；Worker 从当前官方地址簿响应取得明确的账号标识、核对同账号与连续授权后，才沿用原选择。账号变化、无法证明连续性、安装变化或撤销后重连需要新确认。数字与名称选择均校验已选地址内容。每次读取仍检查会员、安装、连接、期限和撤权；不会共享其他会员的地址或授权。详见[账号连续性](token-account-continuity-2026-10-20.md)。

旧密文凭据与旧选择记录可在升级后读取；首次同凭据续期沿用其原有选择上下文。新 grant 的选择上下文与授权 epoch 受到密文认证绑定。回退部署须恢复匹配的代码、业务库和密钥备份，不混跑新旧 Worker。

## 验证

自动回归覆盖跨32次累计调用的原任务续办、连续窗口暂停、累计上限不能重置、原任务扩展预算、等待七天后的续办、幂等恢复、来源实际到期及同凭据续期、解释结果复用、旧密文兼容、凭据／安装变化、撤销、地址内容变化、方向更改、取消与迟到回包。测试中的模型和供应商数据为隔离替身。

类型检查、489项自动测试、构建、9项进程级 E2E 和差异检查通过。额度临界及单次推理耗尽均保留可续办状态；原有来源隔离、取消、撤权和迟到结果保护继续通过。

随后[真实 PA 验证](evidence/task-recovery-live-2026-10-20/README.md)已完成：同一 Task 仅提交一次、补充一次，经历两次来源恢复后完成真实费用预览；地址没有重复要求确认。19次实际模型调用和全部已确认读取记录保留，最后恢复前的8次调用没有清零，续期后没有重复解释需求。PA MCP、独立 A2A 与持久化结果一致，全程未下单付款。该实际证据与上述隔离自动回归分别记录。
