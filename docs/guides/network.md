# 会员协作网络

协作网络默认关闭，通过 `EIGOS_NETWORK_ENABLED`、邀请范围和角色配置显式启用。成员可以管理自己的需求、服务草稿、结构化回复、私有关注、询价和经过批准的结果摘要。

可见内容受圈子、发布状态和精确许可约束。成员身份、来源账号、内容发布和业务执行各有自己的授权。发布服务 listing 不会把发布者的供应商凭据借给其他会员。

Agent 使用 `network_query` 查询可见数据，使用 `network_command` 管理自己的内容，使用 `network_get_command` 回读命令收据。发布和代表他人行动需要相应控制人的明确批准；Agent 不能代替控制人审批。

`network_updates` 返回当前仍有权限的数据更新。客户端保存游标、按事件 ID 去重；收到 `CURSOR_STALE` 后清理旧缓存并重新读取。更新拉取不会启动模型、下单或对外推送。

已确认的社交选择可以转换为私有任务或报价选择，之后仍通过同一任务核心、本体版本和准确授权执行。撤销父级权限后，相关收据和消息按当前权限重新判断，不重放已撤回内容。
