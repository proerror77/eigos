# 单次模型决策的只读执行

本体 v26 支持把一个明确的只读目标、动作选择和依赖放在同一次模型请求中。Worker 先读取实际获准的任务上下文和准确动作合同；模型返回一次结构化计划；Worker 初始化技术 scope、绑定已接受的来源输出、执行确定性选择，并独立核验结果。

模型调用不附带工具。执行器拒绝隐藏的工具交互或第二个完成回合；没有专用于 prepare、参数拼接或宣布成功的模型调用。一次客户端模型调用与上游服务内部不可观测的重试仍是不同指标。

## 适用范围

当前先使用已配置的原生 Worker 模型和完整的能力引导目录。候选只读模块必须在本体中声明允许的依赖、纯函数选择和 planned completion。输入、原始消息及合同必须能完整放入现有有界读取。跨服务或仍需业务选择的目标保留通用目标流程；目录被截断、长历史或旧发布版本不能伪装成单次决策。

简单路径的模型提案包含完整目标和原始消息引用、准确能力、输入、动作依赖与未来结果引用。程序拒绝未注册动作、写入动作、遗漏的硬约束、不受支持的业务阶段，以及缺少来源证据的完成声明。一次模型仍负责自然语言解释；模式校验不等于对任意自然语言含义的数学证明。未表达清楚的要求必须澄清或进入适当的规划路径。

## 先使用业务上下文

首次上下文可以省略一般类型定义，准确动作合同另行读取，业务事实和原始指令仍完整保留。当前位置沿用当前任务已取得的位置事实及其实际观察时间；默认住址和旧上车点不能替代当前位置。

对于显式选择且获准访问的个人业务引用，可沿已发布的只读 Interface 关系读取其地点。活动通过 Located，航段或交通通过 OriginDestination 复用既有 Place；读取范围、关系方向、字段和当前任务权限仍检查。它不会反向遍历 Person 的全部历史，也不会为查一个地点调用供应商。

活动时间和地点是规划事实。报名、接单、接驾、到达各有自己的结果证据，不能由这些关系推定。

## 当前检查与兼容

新的 GoalCoverage.reviewOrigin 为 ontology_read_contract，明确表示程序核对已声明的只读目标合同。旧的 independent_turn 和 registered_fixed_input 保持原验证逻辑和原模型回执要求。历史 v25 构造、任务发布引用和源证据不被改写。

源码升级不会自动激活存量数据库的新合同。正式运行需要在既有单写维护窗口中，先以实际 policy digest/revision 预览并执行 scripts/upgrade-single-read-policy.mjs，再以 active digest/generation 执行 scripts/install-single-read-contract.mjs。两个工具保留原授权、有效期及已有任务发布引用，不新增动作或函数权限。先完成常规构建；安装脚本读取 dist/。正式部署与合并按任务实际授权执行。

每次外部调用仍检查当前源授权、凭据、取消和租约。DiDi 连接器仅短暂复用同一固定账号绑定下已校验的工具 schema；并行的同一任务读取合并目录请求。权限和供应商结果不缓存为许可，显式发现仍读取当前目录，错误会清除目录缓存。

## 测量

scripts/measure-readonly-task.mjs 使用新建的隔离 Foundation 验证库、实际 Worker、配置中的真实模型及滴滴只读接口。它保留原凭据文件和绑定标识，不改正式任务库、会员库、Source 授权或部署。隔离身份用于验证权限执行，不代表原 PA 的真实身份；这项测量也不包括公开 Gateway、原 PA 或 Relay 的网络时间。

构建后传入私有配置、新的仓库外输出目录、城市和起终点；默认只预览。显式加 --run-readonly 才发送读取。每次验证最多一次客户端模型请求和三次供应商业务读取，目录与握手另计。实例参数示例：

    node scripts/measure-readonly-task.mjs --config /absolute/private/server.env --output /absolute/local-archive/new-run --city 上海市 --origin 上海虹桥站 --destination 上海浦东国际机场2号航站楼 --class 专车 --run-readonly

输出记录初始化耗时、提交到完成耗时、模型调用次数和时间、Ontology 读取、MCP 握手/目录/业务请求、来源操作时间及独立回读结果。真实结果与计时保存在仓库外，不提交凭据、数据库或真实响应。

运行代码、数据规模、模型和来源条件必须一并说明。合成测试证明调用和权限行为，真实联调证明该样本的速度；单次测量不能声称 p95 或任意任务的固定秒数。报价成功也不代表已真实叫车或付款。
