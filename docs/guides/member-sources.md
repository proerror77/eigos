# PA 自有账号与来源授权

客户的滴滴、日历等第三方账号、Key、付款信息和钱包绑定在客户自己的 PA，由其私有连接机制保管。开通 EIGOS 会员不迁移这些绑定，也不授予服务器操作人的供应商账号。凭据不经过 EIGOS 网站、MCP 参数、任务文本、模型上下文或普通 PA 消息。

1. PA 发现任务确实需要的服务与最少数据范围，不在会员注册时预先要求所有服务授权。
2. 缺少连接时，由 PA 在自身支持的私有流程中引导本人登录服务商。EIGOS 不索取 Key、Cookie、密码或付款凭据。
3. EIGOS 的安装、任务及数据协作许可仍单独审阅。需要从客户 PA 取得数据时，使用已配置的 PA／Source 合同，绑定准确任务、请求版本、动作、有效期和结果字段；PA 在本地使用凭据，只返回获准的事实与证据。
4. 如当前宿主或实例没有兼容的来源桥接，报告尚未接通；批准一个已有 Source 不能当作客户已登录自己的滴滴或日历账号，普通消息或自报状态也不是服务结果证明。
5. 账号授权失效或用户撤销时，停止后续读取；任务恢复继续原任务并重新核对权限，不自动延长旧授权。付款由 PA 自有能力和独立明确许可处理，本轮接入不启用下单或付款。

现有只读来源协议及凭据留在来源宿主的部署见[Relay 任务与服务来源](relay-tasks.md)。来源桥接、客户账号授权、来源实际查询、独立任务验收与 PA 收到结果分别核验；协议实现存在不代表任意 PA 已部署或启用该能力。

## 历史 legacy 凭据上传兼容模式

下述通用会员凭据上传与 `AgentConnector.connectSource` 只说明既有 **legacy 且显式启用会员来源配置** 的兼容实现，不用于新客户接入，也不由本轮开启或迁移。正式 foundation 实例不提供该通用 Token 上传入口。保留已有历史任务和权限，不为适配新流程自动改写它们。foundation 的来源授权与原任务恢复见[接入指南](../integration.md#任务接口)。

1. PA 读取 `list_source_connections` 与 `get_source_connection`。
2. `begin_source_connection` 返回当前身份绑定的上传请求。
3. PA 在本机取得本人凭据，通过 SDK `AgentConnector.connectSource` 的 `loadCredential` 回调上传。
4. 再次读取连接状态；需要继续任务时使用原 `taskId` 和当前版本调用 `resume_source_task`。
5. 撤销使用 `revoke_source_connection`；它不代表供应商账号本身已注销。

连接绑定 owner、客户端／安装、版本、期限和读取程序。私有业务库保存加密密文，密钥单独存放并限制文件权限。Gateway、Worker 和供应商 MCP 对配置、版本、有效期及撤权状态分别检查；会员读取不会回退到服务器操作人的凭据。

配置使用 `EIGOS_MEMBER_SOURCE_KEY_FILE` 和 `EIGOS_PAOTUI_SKILL_DIR`。显式单会员兼容模式使用 `EIGOS_PAOTUI_MEMBER_CONNECTION_FILE`，两者互斥。部署配置和身份要求见[会员指南](membership.md)及[配置模板](../../.env.example)。

已有地址选择只在来源证明同一账号、授权与所选内容仍有效时复用。来源变更使旧观察失效；恢复继续原任务并重新读取来源，不能生成新的业务许可。来源接入成功和真实查价完成分别判断。
