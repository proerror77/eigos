# 部署入口与验收

| 入口 | 用途 |
| --- | --- |
| `npm run setup:pa`、`setup:local-pa` | 管理本人本机 Gateway／Worker 常驻实例及已有本地来源配置 |
| `npm run setup:primary-pa` | 为 PA 配置主会员实例的原生客户端 |
| `scripts/deploy-member-network.mjs` | 按显式 profile 管理会员网络、邀请测试或私密未付款结账实例 |
| `Dockerfile` | 构建 Gateway／Worker 运行镜像 |

先使用仓库锁文件构建并验证。配置、任务库、会员库和凭据保存在私有位置；部署快照包含相同的代码、JSON 资源和依赖摘要。安装器按所有权管理运行目录，失败保留或恢复先前配置。

每个 Gateway／Worker 组合使用一个共享业务库和一致的已发布本体。当前版本不可用时任务应暂停；不能悄悄用另一份定义解释已固定的计划。已有数据库迁移须核对原版本、备份、事实兼容和独立读回。

更新后核对 `/health`、Agent Card、认证拒绝路径、实例标识与构建摘要。需要浏览器操作代理的来源还要核对来源队列及代理在线状态。进程就绪不代表供应商账号可用，更不代表业务已经完成。

部署命令和真实业务命令有外部效果。运行前使用该次任务已经授予的部署与业务权限；仓库 CI 成功本身不会发布或迁移实例。
