# 美团只读来源

美团接入提供公开地点、本人保存地址及费用预览。动作选择和顺序由模型依据当前本体决定；每次供应商调用对应一个获准读取。当前来源不提供真实下单或付款权限。

本人本机模式通过 `EIGOS_PAOTUI_SKILL_DIR` 连接官方查询工具，使用 `MeituanReadTask` 和独立的 MCP 绑定数据。公开地点限制可由 `EIGOS_PUBLIC_GEO_DISCOVERY_QUERIES` 显式配置。

会员模式通过自己的加密来源连接使用 `PaotuiTask`、包裹、路线与地址对象，见[会员来源连接](../guides/member-sources.md)。两个来源策略都登记在同一个本体注册库，按当前身份和配置启用；供应商协议适配位于 `apps/provider-mcp/`。

地址选项、联系人、电话及原生地址标识留在 owner／任务私有上下文。模型只能使用实际展示、由用户选择且仍与当前来源匹配的选项。报价必须对应同一凭据上下文、当前包裹和两端地址；报价不是最终费用、订单或配送承诺。

执行账本保留来源回执、版本与独立验收。取消、撤权或租约失效后的迟到数据不能改变任务选择或制造完成事实。合成测试和历史只读检查不代表当前账号已授权。
