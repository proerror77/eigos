# 能力与验收范围

运行时以认证后的 `list_services`、本体发现结果和当前配置为准。定义存在、程序已注册和某个账号当前可执行是不同状态。

| 能力 | 配置或来源 | 完成含义 |
| --- | --- | --- |
| 任务说明与文档 | 本地制品程序；文档生成需要模型执行器 | 已生成所请求的制品，不能替代外部业务目标 |
| CSV 审计 | 显式本地输入目录 | 对固定输入完成指定审计；合成输入只证明模拟检查 |
| 受管本体数据 | 本体发布、受限声明式动作与准确预览授权 | 已提交并回读受管对象变更 |
| 美团 | 本人本机来源或会员自己的连接 | 地点、地址和费用观察；不证明下单、付款或配送 |
| 滴滴 | 私有绑定及只读工具；模拟订单单独开启 | 地点与车型估价；mock 订单只属于模拟环境 |
| Shopify 商品目录 | 显式商家清单 | 有来源的商品事实；库存数量、配送与合作关系仍须单独验证 |
| Shopify 未付款结账 | 私密配置、准确商家和商品范围、单次草稿授权 | 已建立原未付款草稿；不等于订单或付款 |
| 免费报名与预约 | 显式参与者来源与在线浏览器操作代理 | 按目标取得提交回执或独立确认的资格；不证明到场 |
| Shopify PA 付款沙箱 | 显式隔离测试来源与 PA 自有测试能力 | 原测试付款与订单分别回读；`realPayment=false`，不证明实际付款 |
| 预约与 PA 付款 | 隔离服务商沙箱及 PA 付款交接 | 预约与付款分别由服务商回读；无需付款时不得制造付款步骤 |
| 交易、UCP 与领域沙箱 | 显式隔离的合成提供方 | 仅证明模拟链路和工程约束 |
| 会员网络 | 邀请、身份、内容与可见性许可 | 发布、询价或协作状态；不自动授权业务执行 |

多服务任务先固定整个目标，再发现动作、准备各服务上下文并组织执行。一个组件完成不会替代其余目标。所有组件共用任务版本、授权账本和独立验收。

未知外部操作保留原操作身份并查证。取消、撤权、任务改版、租约失效和迟到结果分别检查；技术暂停保留已有事实，不要求用户重复确认已知信息。

详细合同见[服务接入导航](../README.md#服务接入)和[共享本体](../../packages/ontology/README.md)。
