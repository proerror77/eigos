# Ontology v0.2：独立业务问题演练题集

日期：2026-10-18。状态：题目与记录要求已定义，演练尚未运行。参照 [Palantir 官方验证方法](https://www.palantir.com/docs/foundry/ontology/ontology-design-validation)；使用合成数据，不调用真实来源或执行真实交易。

参与者只取得题目、从定义目录导出的业务类型／属性／关系说明、获准数据及通用查询／导航／函数能力；不取得整个规格仓库、场景答案、答案链接或预先安排的路径，也不使用为某题专门制作的流程页面。非建模者与 Agent 分别作答；Agent 使用不含建模对话或答案记录的新上下文，不读取人的操作路径。实际演练可在业务含义不变的情况下更换数据和参数，记录题目／数据版本，避免按已排练的流程复述。

## 记录与判定

每题记录：参与者类型及是否参与建模、起始／结束时间、搜索词、访问的对象和关系、调用的计算／动作提议、答案及证据、求助／人工拼接情况、权限或来源缺口。未允许的写动作只能描述提议，不能提交。

验收要求：结论与已给事实一致；未知被明确保留；能说明对象和证据路径；没有借用隐藏的实现知识、其他人的路径、越权字段或专用脚本完成。耗时先记录作为基线，不虚设尚无依据的速度门槛。

错误要区分模型语义、关系缺失、数据缺失、权限、工具能力和使用说明问题。题目不因现有模型答不出而删除；修正对应问题后再演练。作者自检、自动规则测试和真实业务验证分别记账。

主持人的预期判断与导航检查单独保存，不提前交给参与者。完成记录不得仅填写“通过”；至少保留答案、依据、耗时和关键路径。
