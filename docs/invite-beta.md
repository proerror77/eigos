# EIGOS MCP 邀请内测接入

本指南用于运营方已经完成上线验收的内测入口。实际地址和公开 OAuth 客户端 ID 以该入口首页提供的信息为准；仓库代码、CI 或本指南本身不代表公网服务已经开放。

## 本轮可以做什么

- 根据本人提供的材料生成 Markdown 文档草稿、会议议程、分析或计划。文档内容仍需本人审阅。
- 整理任务说明和验收要求。任务说明的完成不代表其中的业务已经执行。
- 在同一个任务中补充信息、查看状态、读取交付物或取消任务。

本轮没有供应商账号连接、真实预订、采购、付款、对外发送或租赁履约。租相机合成演练的结果不作为本轮真实可购买服务。运行主机休眠、离线或模型服务不可用时，内测服务可能暂时不可用。

## 首次接入

1. 打开运营方提供的 HTTPS 入口，进入会员中心。本人登录、填写资料并同意开通后，状态为等待邀请。
2. 从运营方取得绑定本人身份的邀请，在会员中心兑换。邀请一次使用且有期限，其他账号不能兑换；本指南不包含邀请凭据。
3. 在安装 Codex 的电脑上，将入口首页生成的公开连接配置加入 `~/.codex/config.toml`。已有同名连接时更新该连接，保留其他配置：

   ```toml
   [mcp_servers.eigos]
   url = "https://实际入口/mcp"

   [mcp_servers.eigos.oauth]
   client_id = "入口提供的公开客户端ID"
   callback_url = "http://127.0.0.1:64517/callback"
   callback_port = 64517
   ```

4. 运行 `codex mcp login eigos`，按提示完成自己的 OAuth 登录与授权。需要重新授权时运行同一命令。无需复制访问令牌或客户端密钥。`64517` 是本机登录回调端口，需与登记值一致；被其他程序占用时先解决占用，变更端口须由运营方同步登记。
5. 在 Codex 中提出需求，例如：

   > 请通过 EIGOS，按以下材料生成一份 30 分钟的中文会议议程：目标是确认下周上线安排，参会者是产品、研发和运营，依次讨论进度、风险和负责人。只交付文档，不发送给他人。

Agent 应发现当前服务、提交一次需求，并保存 taskId。必要补充在同一个任务中回复；最终读取服务端完成状态与文档。网络超时后先读取原任务，避免重复提交。

Grok Bot 使用同一 `/mcp` 地址和公开 client ID，通过宿主原生连接管理填写 `auth.CLIENT_ID` 与 `scopes=["openid","offline_access","services:read","tasks:read","tasks:write"]`，不填 client secret。其 OAuth 回调必须精确登记为 `https://www.cursor.com/agents/mcp/oauth/callback`。公开资源标识采用 origin 的规范 URL（包含根路径 `/`），必须与 Auth0 API Identifier 一致。

A2A 使用同一 origin 的 AgentConnector 设备授权，独立保管本人的轮换凭据。两条协议的同任务验收见[原生本体运行说明](native-ontology-runtime.md)；某一客户端的历史成功不能代替当前 Grok 链路的实测。

## 账号与停用

每名用户使用自己的身份、会员资格和 OAuth 授权。公开客户端 ID 只是连接配置，不是共享账号或服务密码。

Codex 管理本人的访问／刷新令牌。可以在 EIGOS 会员中心停用本人的客户端连接；已签发令牌和后续刷新不能恢复该连接的调用资格。该操作不删除既有任务，也不撤回已经产生的文档。

本轮原生 MCP 采用会员与 OAuth 客户端连接的管理粒度；同一会员使用同一 OAuth 客户端的多个安装会受同一个连接停用状态约束。已有 Node AgentConnector 的独立安装登记流程另见[Agent 接入](agent-onboarding.md)，两种接入方式不混称为相同的安装级撤权。

任务消息与交付物会持久保存，用于续办、状态查询和回读。登录密码、OAuth 令牌及供应商凭据不应写进任务内容或发送给模型。

## 遇到问题

| 情况 | 处理方式 |
| --- | --- |
| 会员等待邀请 | 保持原会员申请，联系运营方提供绑定该身份的邀请 |
| 需要重新登录 | 运行 `codex mcp login eigos`，完成本人授权 |
| 客户端连接已停用 | 本人在会员中心检查并决定是否恢复 |
| 缺少业务信息 | 在原 taskId 中回答实际业务问题 |
| 技术暂停或网络中断 | 保留 taskId，先查询现有状态；不要重复创建任务 |
| 不支持某项真实业务 | 当前服务未接通该执行能力，不能用一份说明文档代替真实完成 |

依据：[Codex MCP 配置与 OAuth](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。运行验收与运维步骤见[内测发布说明](invite-beta-operations.md)。
