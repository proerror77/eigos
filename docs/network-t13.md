## 已验证的组合链

以 T11 `54904cb` 为基线，包含 `aa50b2a` 的本体／UCP／Shopify 现有改动。当前运行契约为 ontology-execution-v7、eigos.business@5。

`tests/network-gateway.test.ts` 的联合测试实际运行本地 HTTP、MCP、A2A、Coordinator 与 SQLite：

1. 两个隔离会员及多个安装，经可信会话绑定，提交代表关系、服务审核与获准需求。
2. MCP 提出私有询价选择；未确认应用、其他 owner 确认及非法 CSRF 均拒绝。
3. 确认后 HTTP/MCP 重试只建立一个 inquiry／Task；Coordinator 只读取所选合成来源两次，未读备用来源。
4. A2A 与私有网页读回相同任务、查询验收及合成等级；对方不能读私有任务／询价。
5. 从控制页实际返回的表单提取准确 payload，经原生表单编码提交报价选择；Agent 应用后网页与 MCP 均报告当前版本有效，业务执行仍未开始。
6. 从原询价生成固定字段摘要，经批准发布。另一个会员读回相同摘要；私有 Task ID、目标和合成地址标记均不出现在圈内卡片中。
7. 从 Task 再准备摘要返回同一卡片。撤销许可后 API 与网页均拒绝旧卡；原 Task 保持一个，没有因协作重启业务。

最近的既有网络测试继续覆盖撤回后的游标复位、私有关注、冒用、重复发布、源纠正、事务回滚、重新打开存储恢复；进程测试继续验证独立 Gateway／Worker、持久领取、迟到结果与取消。测试通过状态见[本轮证据](evidence/network-t12-t13-2026-10-19/README.md)。
