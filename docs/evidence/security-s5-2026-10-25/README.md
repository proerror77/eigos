# S5 验证记录（2026-10-25）

本轮实现与隔离验证覆盖离线复制迁移、Node／Python PA v2、原生来源安全投影、浏览器派发复核和受限原操作查证。详细合同与 T01–T18 对照见 [S5 说明](../../security-s5.md)。

真实常驻数据库通过 SQLite 备份形成闭合快照，原服务继续运行。迁移保存 48 个任务、568 个对象、1053 条关系、各 114 条执行意图／尝试／观察和 55 条幂等回执；会员快照逐字节保留。5 个明确的私有目录共 130 个文件被复制并完整校验。26 个对象满足候选绑定证明，542 个历史对象仅保留为私有归档；激活绑定和自动安全许可均为 0。源副本未被改写。

可公开摘要位于 [summary.json](summary.json)。原始数据库、访问凭据、环境文件、来源响应、浏览器证据和完整测试输出仅保存在私有目录，未提交到仓库。

真实登录准备使用现有 Auth0 配置和现有 HTTPS 接入；没有更改提供者客户端、令牌期限、公开服务或账户策略。两个安装已生成登记 ID，但没有绑定会员或获得令牌。用户说明暂时无法登录后，停止了设备轮询及隔离 Gateway。真实双安装验收、真实模型／来源 round trip、常驻切换及切换后独立读回仍未完成。常驻的开发身份及数据保持原状。

定向测试曾发现并修正 SDK 上下文请求方式、沙箱来源的旧开发身份限制、原生海关参考字段比较和重复权限复核耗时。合成测试身份采用足够完成多步骤流程的 15 分钟令牌寿命；没有放宽 Worker 的租约。完整验证以最终结果为准，原始失败输出保留在私有测试目录供排查。

最终本地验证：`npm run check`、完整 682 项 `npm test`、`npm run build`、11 项编译后 E2E、83 路径的 S0 清单及 `git diff --check` 通过。最后审查收紧了客户端版本参数和同步读取上下文的异步存活边界；新增一条异步边界回归后，受影响的 25 项安全／客户端检查和完整 11 项编译后 E2E 再次通过。CI 以同步提交的准确 SHA 独立回读，不由本地记录推断。

迁移最终检查另覆盖了“没有活跃 grant，但已有新的策略变更”的情况：启用前 verify 拒绝此状态。4 项迁移与 8 项清单回归通过，常驻快照的原始迁移副本再次通过 verify；新库一旦承接授权／撤销事实就不能用于自动恢复 legacy。
