## 实现及验收

- `EIGOS_PUBLIC_GEO_DISCOVERY_QUERIES` 省略或为 `[]` 时保持新发现源关闭。非空时按相同共享 schema 解析城市／关键词，每项严格限制字段、长度和首尾空白，最多 16 项，原始 JSON 最多 16,384 字符。错误配置启动即拒绝，错误信息不回显查询内容。
- 非空清单必须有既有个人读取器配置，只允许非生产、开发身份和 loopback。Gateway 与 Worker 均将解析清单传给 catalog；清单通过来源配置摘要固定在计划中。
- 运行清单允许重复匹配查询，不是一次调用额度。它不会继承此前一次公开查询的授权；任务内容和模型不能改变清单。
- Gateway 只登记发现源并提交任务。Worker 经该发现源获取一个搜索服务候选，保留 `realSupply=false`，不创建 Offer 或商家履约事实。
