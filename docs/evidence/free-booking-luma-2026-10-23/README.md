## 来源与限制

- 平台操作通过当前已登录的 Luma 普通参与者网页完成，未使用主办方 Add Guests、Luma Plus 或私有 API。
- 浏览器操作由本次 Codex Computer Use 在线代理完成；这不是无人值守来源，也不代表 EIGOS 已获得任意 Luma 活动的自动报名 API 权限。
- 报名提交与重新打开活动页的确认分别保存来源观察，等级为 `live_operation` 和 `live_readonly`。这些是本机授权浏览器观察，不是 Luma 签名的 API 回执，也不证明活动到场或后续服务交付。
- `registrationId` 是同一参与者与活动的本地稳定跟踪键，确认引用为原活动页；没有将本地键冒充 Luma 签发的票号。
- 原始页面文字、带邮箱／访问参数的截图、门票二维码、配置及凭据只保存在忽略的私有会话目录；此处只归档已检查的摘要及哈希。无日历工具写入、付费操作或另行对外联系。
- 通用预约、待审核、候补和拒绝状态另由合成回归及协议测试验证。本次真实来源只验证上述免费活动的确认路径，不据此宣称其他预约平台或实际审核等待已验证。
