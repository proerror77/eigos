此前[已知变体 ID 的真实后端诊断](../ontology-runtime-2026-10-19/README.md)由模型选择 2 个动作；本轮按商品名比较由模型选择 7 个动作。两次使用同一执行代码，业务目标和模型动作轨迹分别记录。这里证明的是已登记的四类只读动作可由模型选择和组合。
