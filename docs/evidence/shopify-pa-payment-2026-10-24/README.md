# Shopify PA 自有支付能力隔离验收

2026-10-24。真实 Codex Personal Agent 与真实 EIGOS Worker 完成一次模型驱动的测试购买；商家为本机 Shopify 合约模拟器，付款为 PA 独立测试 Vault。没有连接官方 Shopify 开发店或真实 Grok Vault，没有真实扣款。

- PA 自行发现服务并提交唯一任务，批准一次零付款花费的结账准备，读取 v3 付款请求，选择自己的测试 Vault，执行 USD 1 模拟付款并通知原任务。
- Worker 实际读取 Ontology、选择原子动作，在付款后分别读取原结账／订单和付款。原 checkout ID、付款操作、金额／币种、收款方和 order ID 全部匹配。
- 原验收只有一个结账和一次模拟付款；PA 最后实际读取完成交付物，独立观察器比对 MCP、A2A、本人任务账本和测试商家记录。
- 首次观察脚本误读组合结果及公开摘要的层级。修复后的只读观察器核验了同一份原交付物，没有重新运行业务模型、创建结账或付款。
- 当前版本交接的 owner、任务、配置和本体关系完整性亦由独立观察器重新检查。现有 v15–v18 本体摘要保持不变。

脱敏结果与原子操作见 [verification.json](verification.json)。私有凭据、完整 PA 工具输出和数据库保留在忽略目录，未归档到仓库。

两种 PA 路线的协议回归覆盖独立 Python PA、A2A 交接、Gateway／Worker 重启、PA 操作账本恢复、MCP 验收及重复通知；它们使用合成模型夹具，与这里的真实模型验收分别记录。运行方式见 [测试环境说明](../../shopify-pa-payment-sandbox.md)。

代码验证：类型检查、构建及 9 项编译后进程测试通过。首次本地全库为 1011/1016 通过，5 项失败分别来自旧测试驱动的租约／提前结束等待、两个旧内核版本断言，以及提前生效的交接完整性校验导致错误文本变化；修正后相关 10 项复核全部通过。远端 CI 另按实际提交 SHA 核验，不把这次中途修复的本地运行标为全量通过。
