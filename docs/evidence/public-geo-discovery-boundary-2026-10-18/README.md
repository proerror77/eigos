## 可用实现与验收边界

`PaotuiGeoDiscoverySource` 复用既有 reader，默认没有允许查询，不能读取来源。可信配置必须显式提供最多 16 组城市和关键词；模型输出和任务内容不能扩展此集合。身份仍限定既有本地开发 owner。

- reader 只收到解析后的 `search_address`、城市和关键词；原始目标、消息、地址簿或额外字段不能随查询发送。
- 结果只接受至多 100 个带类型约束的地点，以及完整 Ontology 回执。额外字段、嵌套未知数据、错误输入/结果摘要、工具、能力或来源调用均拒绝。
- 来源时间不得在未来或超过五分钟；计划候选沿用该时间和期限，不在发现时延长事实有效期。
- 返回非空地点时生成一个查询服务候选；不会为每个地点创建商家绑定或 Offer。没有商品、库存、价格、交付时刻或履约事实；`realSupply` 始终为 false，包括拒绝、故障与超时路径。
- 读结果复用准备阶段的精确回执。独立 verifier 拒绝替换结果或回执，重新打开数据库后的计划仍必须匹配原 owner、任务及来源配置摘要。
- 查询白名单或 reader 配置变化会阻止恢复旧发现绑定。此检查是配置固定检查，不是对上游程序版本或服务可用性的证明。

`createExecutionCatalog` 提供可选 `publicGeoDiscoveryQueries` 参数。显式传入非空列表时才注册来源，并替换该 catalog 中重复的静态 geo 绑定。未传入时维持现有行为；网关/Worker 的环境配置尚未接入此选项，运行服务没有启用新来源。真实数据格式兼容性仍待获授权后验证。
