## 保护机制的工程测试

工程测试覆盖模型不读规则、只读规则却不计算关卡、缺失／重复条款、未登记规则版本、过期／未来适用时间，以及取得准确 PA 许可之后参考资料被改动。上述情形均不能进入对应报价或交易动作。受管制或未知商品分类也不能通过购买范围检查。

空商家目录的退出缺口已修复：在实际读取并计算原查询的空结果后，可以返回已注册来源不支持；不会由该分支连续重试后要求 PA 补充信息。另一个查询的空目录不能作为本次请求的拒绝依据。

379 项测试、7 项进程端到端检查、类型检查、构建及差异检查通过。测试替身覆盖的拒绝分支与上述真实模型只读运行分别记录；本次没有声称真实模型又执行了完整模拟下单链路。
