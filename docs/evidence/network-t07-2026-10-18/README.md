## 直接验收项

| 场景 | 结果 |
| --- | --- |
| 邀请指向特定会员 | 其他会员不能接受；未接受者不能读取圈内目录 |
| 邀请过期/撤销/圈 epoch 改变 | 原邀请不可继续使用 |
| 普通成员自升管理角色 | 拒绝；运营角色由配置决定 |
| 成员移除后再加入 | 新 generation，旧共享仍不可读，需重新批准 |
| 圈归档后重新开放 | 旧发布许可不复活 |
| 资料改名/停用 | profileId 不变；私有改名不改变批准的公开正文；停用撤销旧共享 |
| 声称代表某主体/自我审核 | 声明保持 pending；同一控制者不能自我核实 |
| 服务无执行绑定 | 显示 introduction_only，candidateEligible=false |
| 来源绑定与账号权限 | 核对 provider/capability/config 摘要；两个账号可得到不同资格；availableNow=unknown |
| 沙箱绑定 | 明确 sandbox_only，不能标成现实可执行供给 |
| 暂停/编辑/退役/角色过期 | 从共享详情与搜索消失；历史和原私有任务保留 |
| 替换发布时故障 | 旧 publication、新许可消耗和事件一起回滚；原键可恢复 |
| 非成员/不在受众的管理员 | 详情与搜索均不返回正文，管理角色没有读取旁路 |
| 目录游标 | 加密隐藏扫描位置，不能跨用户或在权限改变后复用 |
| 管理权限被移除后重放旧命令 | 不凭历史存储 owner 绕过当前管理权限 |
| 数据库重开 | 圈/成员/服务记录仍在；不重复初始化默认成员 |
| HTTP/MCP 与页面 | 使用同一服务判权；页面转义文本，未包含私人核验备注/凭证引用 |
