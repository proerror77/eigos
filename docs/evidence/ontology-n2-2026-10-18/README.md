## 独立 Agent 演练

两轮分别使用新的 Agent 上下文，未继承建模对话、源码、场景答案或答案路径。参与者仅获连接文件、题目、通用工具 schema 和获准合成数据；数据通过 HTTP 查询取得，程序记录每次调用和每题答卷。它们均声明未读取额外资料、未向建模者求助。这里声明的是上下文和信息使用边界，不宣称操作系统层面的文件隔离。

| 轮次 | 作答／复核 | 求助 | 各题耗时之和 | 工具调用 |
| --- | --- | --- | --- | --- |
| 首轮新上下文 | 9 题提交；8 题通过，QG-2 需修正 | 0 | 16 分 03.417 秒 | 90 |
| 第二轮新上下文 | 9 题提交；9 题通过数据与查询记录复核 | 0 | 9 分 25.893 秒 | 104 |

耗时从每题首次工具调用到提交答卷计，不能据两次探索性演练推断普遍性能提升。`saved:true` 只证明答卷保存，评分由维护者对实际数据和查询轨迹逐项核对。
