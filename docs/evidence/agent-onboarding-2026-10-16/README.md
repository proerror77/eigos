## 证据和能力边界

刷新后的签名 `agent_enrollment` claim 为 false；新登记不能仅凭刷新 grant 建立，旧初始访问令牌也不能绑定另一安装实例。跨用户、scope 缺失、邀请重放、网页邀请制、并发缓存到期、不确定刷新结果及私有凭据恢复由本地回归补充验证。

[源码摘要](source-sha256.json)记录最终交付版本；真实链路回执与本地回归分别证明实际调用和补充的拒绝／恢复行为。

交付检查：103 项全量测试、类型检查、构建和差异空白检查通过；覆盖绑定响应丢失后的恢复，以及新增 Agent 不改写已有会员资料。

本轮使用独立会员／任务数据库，真实会员身份与上一次接入验证一致，但保留了原会员库。验收 Agent 已停用，正常私有环境恢复使用原数据库和自助开通模式。令牌轮换由 Agent 端适配器完成；只配置一次静态 Bearer Token 的外部客户端需要接入适配器或实现相同续期流程。

这证明预登记 connector 软件客户端下的 Agent 安装实例自助登记及授权链路，不代表所有外部 MCP 客户端的 CIMD／DCR 自动 OAuth 已兼容，也不代表公网生产发布或商业订单履约完成。
