## 实际模型验证

[脱敏摘要](model-summary.json)记录实际 `codex-exec` Worker 运行：24 个模型轮次、同一个 Task 的地址补问及用户回复，随后读取当前版本地址簿、两次地址详情和一次费用预估，共 5 个单次来源读取。模型对旧版本观察的状态判断为未知，重新选择当前读取；最终主动读取并评估报价观察后提交完成，独立来源与条件验收通过。

这次使用真实模型，供应商响应全部为本地合成数据，调用方是测试驱动。它证明模型使用本体、选择动作并依据观察完成，不证明真实 PA、当前会员账号或真实美团查价已通过。原始模型记录与含私有格式的调用记录保留在忽略目录，未归档到 Git。

首次诊断驱动未续租，实际模型返回时领取已失效，被运行时拒绝且未发出供应商调用。改用项目已有 Worker 的续租后，上述演练通过。租约失效回包和不自动重放另有确定性回归测试。

开发同步、私有环境运行、Auth0 用户授权与供应商查询分别验收。此证据没有真实订单、付款或履约。
