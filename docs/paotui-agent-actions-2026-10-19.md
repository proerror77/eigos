# 美团查询：v8 Agent 与会员自有授权

本轮合并主线 v8 AgentRuntime 与已有会员来源授权，再将当前美团地址簿和查价能力切换到模型选择动作。`delivery.quote@3` 和 `address.book.read@2` 的解释输入为空对象；解释阶段只建立受限范围。模型从本体读取范围、动作定义和已观察结果，自行选择 `ReadSavedAddresses`、`ReadSavedAddressDetail`、`PreviewDeliveryQuote`、参数、依赖、补问或完成。当前目录不再注册旧固定查价适配器。

## 复用与边界

- 继续使用共享 Task、持久领取、取消、租约、动作账本、模型决策摘要、原子观察投影和迟到结果保护。中断读取不自动重放。
- 每个 Worker → stdio MCP → 官方 CLI 调用只执行一个读取操作，回执固定输入／结果摘要和唯一命令。没有隐藏地址查询、自动选址、自动重复预览或交易工具。
- 会员使用自己的加密来源连接。Gateway 不读供应商；Worker／内部 MCP 在调用前后核对授权，投影和完成再次校验。撤销、过期、账号轮换会暂停任务；重新连接后归档旧 Agent 状态、保留预算，在同一 taskId 建立新范围。
- 地址、联系人、电话、供应商 ID 和坐标保存在受限本体属性及私有账本中，模型只读安全摘要。模型提出补问时，宿主只在本人任务回复中插入实际地址列表。令牌不进入上述任何模型或 Task 数据。
- 地址名称须来自用户消息并唯一匹配；数字选项须在本任务展示列表后的回复中使用。仅重排列表保持编号，地址内容变更废弃旧编号。物品、类别、重量、服务须有用户依据；缺失信息不能用默认值补齐。
- 保存地址坐标严格沿用官方整数微度，城市 ID 以数值传给预览接口。公开 POI 的独立转换规则保持原作用域。

## 本体、询价与证据

新增 `PaotuiTask`、`PaotuiObservation` 和 `paotuiObservationStatus`；全模型为 `eigos.business@8`，71 类型、26 函数。每次观察绑定当前来源连接、请求版本、模型轮次、计划、意图、尝试及单次供应商回执。预览映射为有来源的 `DeliveryQuote`、`Parcel`、`DeliveryRoute`；路线使用不含详细地址的引用。

完成需要模型实际读取并评估所选观察，程序再次检查新鲜度、来源、明确选址、物品参数、当前请求及硬条件。费用对象标记为 estimate，完整费用范围未知；不升级为确定报价或履约。

服务 listing 的绑定是程序元数据，不包含发布者凭据。T10 指定来源询价在初始化、验证、调用前后、投影和完成时保留审核来源、成员资格及买方身份检查，不增加其他来源回退。新结果复用原报价选择／Proposal 接口。T11 分享仍只生成原七字段允许清单；历史查询证据还须核对模型完成决策、依赖动作账本、来源快照和回执，不能仅凭 completed 状态升级。卡片不保证当前价格、可用性、订单或履约。

旧 listing 的能力版本和绑定摘要不会自动迁移，须按新版本重新审核；旧任务不重放。不涉及公开发布、生产切换、真实订单或付款。

## 验证范围

自动验证包含模型选地址簿或分步详情／查价、同任务补问、私有属性禁止读取和过滤、未知／虚构／跨任务参数拒绝、缺少用户事实拒绝、观察过期、地址变化、取消／租约失效的迟到返回、两个 JWT 会员各用本人凭据、调用中撤销、连接轮换后的同任务恢复、指定来源网络询价及七字段证据降级。

实际模型验证、开发同步和私有部署的结果分别归档；隔离 CLI／模型 fixtures 不作为真实美团账号查询证据。后续在本人完成平台授权后，已单独验证真实会员 PA 和美团地址簿读取，见 [真实账号回路](evidence/member-source-live-2026-10-19/README.md)。

本轮已完成 475 项测试、9 项进程级 E2E、实际模型合成来源验证、代码 CI 和私有 v8 部署回读，详见 [验证与部署记录](evidence/paotui-agent-v8-2026-10-19/README.md)。随后已完成一次真实本人地址簿查询；真实查价和交易不在该次验证范围。
